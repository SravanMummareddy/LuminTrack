## High

| # | Page | Issue | Fix sketch |
|---|---|---|---|
| H1 | Dashboard / Reports / Recruiters | **Duplicate users in dropdowns + perf table** — "Marcus Lee" and "Priya Sharma" appear twice (different IDs, zero stats on dups). Both seed flows (`seed-demo.ts` vs `seed.ts`) created the same recruiter emails. | Dedupe seed users by email; add `DISTINCT` / `groupBy` on the user query feeding the dropdowns. |
| H2 | `/` Dashboard | **Recruiter-row absolute click overlay blocks interactive children** (`::before absolute inset-0` on `<a>`). Recharts tooltips and inline badges are dead under the overlay. | Either `pointer-events-none` on the `::before` and wrap only the name in `<a>`, or pull interactive children out of the row. |
| H3 | `/candidates/[id]` | **"Mark contacted" is a plain text-link button that mutates server state instantly** — no confirm, no toast, easy mis-tap on mobile. | Style as a proper button, place next to the "Last contacted" row, show timestamp inline, brief confirmation toast. |
| H4 | `/jobs/import` (admin), all non-app routes | **Blocked admin routes return Next default 404** (no chrome) instead of a 403/Forbidden. Bare 404 also fires for any unknown root path — `dashboard/not-found.tsx` doesn't catch root-level misses. | Add root `src/app/not-found.tsx` with app chrome + "Back to dashboard"; return a styled 403 (not `notFound()`) for role-gated routes. |
| H5 | `/submissions/[id]`, `/candidates/[id]` | **iframe `sandbox="allow-scripts allow-same-origin"`** — documented sandbox-escape combo. Cross-origin (`drive.google.com`) makes it safe *today*; will break if a Blob preview proxy lands. Also missing `loading="lazy"`. | Drop `allow-same-origin` if Drive still renders; add `loading="lazy"`. PR #C in the closed audit set this — combo is intentional for Drive but worth a comment. |
| H6 | `/jobs/import` | **File-input label has no `htmlFor`; input has no `id`** — screen readers can't pair them. | Add matching `id`/`htmlFor` or wrap input in label. |
| H7 | `/reports` @ tablet | **6 of 10 tables overflow card width with no scroll affordance** (no fade, no scrollbar). Feels truncated. | Add right-edge fade or stack into cards at `≤md`. |
